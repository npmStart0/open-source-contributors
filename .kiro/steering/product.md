# Product — Open Source Contributors

## מטרת המוצר

Open Source Contributors הוא אתר קהילתי בקוד פתוח המציג מפתחים ומפתחות שבחרו
להוסיף את הפרופיל שלהם למאגר. התרומה נעשית דרך Pull Request ל-GitHub בלבד, ללא
צורך בשינוי קוד React.

## משתמשים

- **תורם (Contributor):** בעל חשבון GitHub שמוסיף קובץ JSON יחיד עם הפרופיל שלו.
- **מבקר (Visitor):** גולש שמעיין בספריית התורמים, מחפש ומסנן.
- **מתחזק (Maintainer):** סוקר ומאשר Pull Requests, מנהל את המאגר.

## עקרונות המוצר

- **קהילה פתוחה:** כל משתמש GitHub יכול להציע פרופיל בתהליך מתועד.
- **תרומה פשוטה:** הוספת קובץ JSON יחיד היא הפעולה המרכזית הנדרשת.
- **איכות באמצעות אוטומציה:** בדיקות אוטומטיות מאמתות נתונים, מבנה, כפילויות ובנייה.
- **נגישות בינלאומית:** ממשק בעברית ובאנגלית עם תמיכה ב-RTL ו-LTR.

## תכולת גרסה 1.0

כלול:
- ספריית תורמים בכרטיסים מעוצבים.
- חיפוש לפי שם ו-GitHub username.
- סינון לפי טכנולוגיות.
- דף הסבר ודף הוראות תרומה.
- הוספת תורמים ללא שינוי בקוד React.
- ולידציה ובדיקות לכל תרומה.
- פריסה אוטומטית ל-GitHub Pages.

לא כלול בגרסה 1.0 (דורש אישור Maintainer להוספה):
- הרשמה והתחברות, GitHub OAuth.
- Backend או מסד נתונים.
- ממשק ניהול תורמים, עריכת פרופילים דרך האתר.
- תגובות, הודעות פרטיות, דירוגים.
- אינטגרציות צד שלישי שאינן נדרשות להצגת פרופילים.

## הגדרת הצלחה

תורם חדש קורא את ההוראות, מוסיף קובץ JSON תקין, פותח PR, עובר בדיקות, מקבל
אישור, ורואה את הפרופיל באתר לאחר הפריסה — ללא התערבות בקוד הממשק.
