# Coding Standards

## עקרונות

- קומפוננטות קטנות בעלות אחריות יחידה.
- הפרדה בין תצוגה, נתונים, תרגומים ופונקציות עזר.
- העדפת פונקציות טהורות ללוגיקה (חיפוש, סינון, ולידציה).
- אי-שינוי (immutability): פונקציות עזר לא משנות את הקלט שלהן.

## TypeScript

- `strict` מופעל.
- טיפוסים מפורשים לממשקים ציבוריים ולערכי החזרה של פונקציות עזר.
- `unknown` במקום `any` עבור קלט לא מהימן (JSON מבחוץ).
- עדיפות ל-schema parsing (Zod) ו-type guards על פני casting.

## React

- רכיבים פונקציונליים עם Hooks.
- Props מוגדרים בטיפוס מפורש.
- אין טקסט ממשק קשיח בתוך רכיבים — שימוש ב-i18n.
- רינדור בטוח של תוכן מהתורם: אין `dangerouslySetInnerHTML` לתוכן לא מהימן.

## נגישות (a11y)

- HTML סמנטי (`main`, `nav`, `section`, כותרות היררכיות).
- ניווט מלא במקלדת ו-focus states נראים.
- תוויות נגישות (`aria-label`, `alt` לתמונות).
- ניגודיות צבעים תקינה.
- `dir` ו-`lang` מתעדכנים לפי השפה הנבחרת.

## איכות

- לכל פונקציונליות חדשה יש להוסיף בדיקות מתאימות.
- אין לסיים משימה לפני הרצת הבדיקות הרלוונטיות ובניית production.
- קוד עובר `npm run lint` ללא שגיאות.

## Git ואבטחה

- אין לבצע Deploy או פעולות Git בלתי הפיכות ללא הרשאה.
- אין סודות בקוד הפרונטאנד.
- יש לעדכן תיעוד כשמשתנים מבנה הנתונים, תהליך התרומה או פקודות הפיתוח.
